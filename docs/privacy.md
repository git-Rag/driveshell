# Privacy Policy — Project Sunflower

**Last updated: 2026-11-06**

Project Sunflower is a free, open-source, personal tool.

- **No data is collected, shared, or transmitted** to any server operated by this project.
- All file metadata is synced directly between your machine and **your own Google Drive** using
  credentials you supply.
- Credentials (OAuth tokens) are stored **only on your device**, in your operating system's native
  keychain (Windows Credential Manager, macOS Keychain, or Linux Secret Service).
- Project Sunflower does not include analytics, telemetry, advertising, or any form of tracking.
- The only network peers this application communicates with are **Google's APIs**
  (drive.googleapis.com) on your behalf.

For questions, open an issue at https://github.com/git-Rag/thesunflowerproject/issues.
